# WarpedAtlas ARPG Engine

A Mesoamerican-themed ARPG overhaul mod for Terraria built on tModLoader (C#). This project focuses on heavy systems engineering, bypassing standard sandbox mechanics to implement custom subworld generation, a deterministic Cartesian-grid passive tree, and custom UI matrix rendering.
